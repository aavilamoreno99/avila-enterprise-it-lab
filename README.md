# Avila-enterprise-it-lab
Laboratorio de infraestructura de TI empresarial centrado en Windows Server, Active Directory, redes, seguridad y automatización.
# Objetivos
El objetivo de este laboratorio es construir progresivamente una infraestructura IT similar a la que puede encontrarse en un entorno empresarial, documentando tanto la configuración como las pruebas realizadas y la resolución de incidencias.

Las principales tecnologías utilizadas son:
· VirtualBox
· Windows Server
· Windows 10
· Active Directory Domain Services
· DNS
· DHCP
· Group Policy
· PowerShell
· Redes TCP/IP
